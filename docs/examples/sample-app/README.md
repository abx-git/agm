# Tekto sample app

Multi-service example. Each service uses **`docs/tekto/`** (steer.md, chapters, interfaces).

| Service | Path |
|---------|------|
| Order | `order-service/docs/tekto/` |
| Payment | `payment-service/docs/tekto/` |
| Notification | `notification-service/docs/tekto/` |

From a service root:

```bash
npx @abx-hh/tekto check
```
